# Supply Chain & Inventory Analytics

## Project Overview
This project analyzes retail sales and inventory data from Maven Toys, a fictional toy retailer in Mexico.

The objective is to evaluate sales performance, inventory levels, product trends, and store performance using SQL and Power BI.

## Business Objectives
- Analyze overall sales performance.
- Identify top-performing products and categories.
- Evaluate store performance.
- Examine inventory levels and potential stock risks.
- Generate actionable business recommendations.

## Tools & Technologies
- SQL (SQLite)
- DBeaver
- Microsoft Power BI
- Excel

## Dataset
The dataset includes five tables:
- Sales
- Products
- Stores
- Inventory
- Calendar

## Project Workflow
1. Data understanding
2. Data quality assessment
3. SQL data analysis
4. Power BI dashboard development
5. Business insights and recommendations
